# 📚 Student Performance Analyzer

## 📌 Project Overview

This project analyzes student performance data to identify patterns and factors influencing academic outcomes. The analysis was performed using Python and data visualization techniques to derive meaningful educational insights.

---

## 🎯 Objective

- Analyze student performance across Mathematics, Reading, and Writing.
- Understand the impact of gender on academic outcomes.
- Evaluate the effect of test preparation courses on performance.
- Explore the relationship between lunch type and student scores.
- Identify high-performing students and subject correlations.

---

## 📊 Key Findings

- Female students performed better in Reading and Writing.
- Male students performed slightly better in Mathematics.
- Students who completed the test preparation course achieved higher average scores.
- Students receiving standard lunch demonstrated better academic outcomes.
- Reading and Writing scores exhibited a strong positive correlation (0.95).
